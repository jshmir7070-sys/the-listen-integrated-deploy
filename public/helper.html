이미지(화면) 보는 방법

실제 이미지 파일 없이 HTML/CSS로 그린 모바일 모형입니다. 아래 방법으로 바로 확인하거나 저장할 수 있습니다.

  • 빠른 열기: 로그인 페이지에서 "Helper 화면 가이드 보기" 버튼을 클릭하면 이 화면으로 이동합니다.
  • 확대/축소: 브라우저에서 Ctrl + + 또는 Ctrl + - (mac: ⌘ + +/-)로 원하는 크기로 확대해 볼 수 있습니다.
  • 저장/공유: Ctrl + P (mac: ⌘ + P)로 인쇄 대화창을 열어 PDF로 저장하거나, 원하는 섹션을 캡처해 이미지를 만들 수 있습니다.

6) 지입 채용 공고 페이지

관리자 또는 사업자 등록한 지입 채용 공고를 확인하고 바로 신청할 수 있도록 구성했습니다.

지입 채용 공고 신규
카테고리택배사/냉장/반배송/기타택배/전체
지입 희망도입 차량, 보증금, 정산조건 안내
신청지원서 작성 후 바로 신청
  • 관리자/사업자 전용 등록 화면에서 지입 공고를 생성합니다.
  • Helper는 공고 상세에서 조건을 확인하고 신청 버튼만 누르면 됩니다.
  • 상태가 변경되면 홈/마이페이지에 알림 배지를 노출합니다.
